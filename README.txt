myPI SPM PWA — DEPLOY READY

LANGKAH:
1. Pastikan Google Apps Script versi FINAL sudah deploy sebagai Web App.
2. Deploy folder PWA ini ke Vercel.
3. Buka URL Vercel.
4. Kali pertama, masukkan URL Apps Script yang berakhir /exec.
5. Install melalui browser: Install app / Add to Home Screen.

PWA shell boleh dibuka offline.
Google Sheet, Gemini AI, kuiz dan analisis memerlukan internet.
API key kekal di Apps Script Properties — tidak berada dalam PWA.
